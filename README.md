# 동현텐 v0.1

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23788169.svg)](https://doi.org/10.5281/zenodo.23788169)

같은 수이거나 **합이 10**인 두 수를 찾아 지우는 숫자 짝 맞추기다. 막혔을 때 쓰는 **Add**와 **Hint**의 횟수를 동현랭으로 정한다.
동현 시리즈의 일곱 번째 작은 실험이다.

바로 하기: https://raspberry-kim.github.io/donghyun-lab6/

## 놀이 방법

- 같은 두 수(3과 3)나 합이 10인 두 수(2와 8)를 차례로 누르면 지워진다.
- 두 수는 가로·세로·대각선으로 이웃해야 한다. 사이에 지워진 칸만 있으면 떨어져 있어도 된다.
- 가로줄은 이어져 있다. 줄 끝의 수는 다음 줄의 첫 수와도 짝이 될 수 있다.
- **Add**: 판에 남은 수를 같은 순서로 맨 뒤에 다시 적는다(파란색).
- **Hint**: 지울 수 있는 짝 하나를 노랗게 보여 준다. 짝이 없으면 Add를 가리키며, 이때는 Hint가 줄지 않는다.
- 지울 짝도 Add도 없으면 끝이다. 판을 다 비우면 다음 판(STAGE)으로 넘어가고, Add와 Hint가 다시 채워진다.

## 점수

| 일 | 점수 |
|---|---|
| 바로 붙은 짝 | 1 |
| 지워진 칸을 사이에 둔 짝 | 4 |
| 한 줄을 모두 지움(그 줄은 판에서 빠짐) | +10 |
| 판을 모두 비움 | +150 |

오늘·이번 주(월요일 시작)·역대 최고 점수는 브라우저의 localStorage에만 저장한다.

## 동현텐 규약

동현랭 코드가 출력한 **정수 둘**이 차례로 Add 횟수와 Hint 횟수다.

| 출력 | 뜻 |
|---|---|
| `7` `3` | 기본값(Add 7, Hint 3) |
| 0–9, 0–9 | 쓸 수 있는 범위. 0이면 그 단추를 쓸 수 없다 |
| 출력 없음 | 기본값 7, 3으로 시작 |
| 정수 하나, 셋 이상, 범위 밖 | 시작하지 않고 오류를 알린다 |

예제는 `01 · 기본 (7 · 3)`, `02 · 아껴 쓰기 (5 · 1)`, `03 · 맨손 (0 · 0)` 셋이다.

```
나는 동현이냐?
ㅋㅋ 기본 · Add 7 · Hint 3
ㅋㅋ Add 7
뿡뿡 도오오오오오오옹~뿡뿡뿡
ㅋㅋ Hint 3
뿡뿡 도오오옹~뿡뿡뿡
동현이구나
```

코드는 판의 숫자나 짝을 고르지 않는다. 첫 판의 수 42개(9칸씩)는 1–9에서 고르게 뽑고, 짝이 하나도 없는 판은 다시 뽑는다.

## 효과음

소리 파일 없이 브라우저 안에서 그 자리에서 합성한다(Web Audio). 수를 고르면 톡, 짝을 지우면 퐁, 틀리면 낮은 부저 소리가 난다. 줄을 지우면 짧은 차임, 판을 비우면 딩동댕이 울린다. Add는 휙, Hint는 반짝이는 소리를 내고, 판이 끝나면 내려가는 세 음이 난다.

기본은 켜져 있다. 머리말의 스피커 단추나 M 키로 켜고 끄며, 고른 상태는 이 브라우저에 남는다. 브라우저 규칙에 따라 첫 클릭·터치·키 입력 뒤부터 소리가 나고, iPhone은 무음 스위치가 켜져 있으면 소리가 나지 않는다.

## 원작에 관하여

이 놀이는 Take Ten·Numberama·Seeds·Number Match 등으로 불리는 오래된 종이 숫자 게임에서 왔다. 대각선 짝과 Add·Hint 구성은 휴대전화 게임 「Matching Numbers」의 규칙 안내를 참고했다. 동현텐은 그 게임들의 코드·그림·글을 쓰지 않았고, 제작사와 관계가 없다. 자세한 내용은 [CREDITS.md](CREDITS.md).
